# von-neumann-machine-simulator

Este é um projeto desenvolvido em C que simula o ciclo de busca, decodificação e execução de uma arquitetura baseada no modelo de von Neumann.

## Como compilar e executar
Para rodar este projeto no Ubuntu, use os comandos:
`gcc main.c loader.c -o simulador`
`./simulador`
